## 4. API

| 方法 | 路径 | 说明 | 状态码 |
| --- | --- | --- | --- |
| POST | `/v1/runs` | 创建 Run，返回 `run_id` | 202 |
| GET | `/v1/runs/{run_id}/events` | SSE 订阅，支持 `Last-Event-ID` | 200 |
| POST | `/v1/runs/{run_id}/cancel` | 取消 Run | 202/200 |
| GET | `/v1/runs/{run_id}` | 查询状态（可选） | 200 |

请求示例：

```bash
curl -i -X POST http://127.0.0.1:8000/v1/runs \
  -H "Content-Type: application/json" \
  -d '{"prompt":"请解释 SSE 的断线重连"}'
```

## 5. 事件协议

```json
{
  "schema_version": "1",
  "run_id": "run_...",
  "seq": 0,
  "type": "run.started",
  "created_at": "2026-11-02T12:00:00Z",
  "data": {}
}
```

事件类型：

- `run.started`
- `text.delta`
- `tool.started`
- `tool.completed`
- `run.retrying`
- `run.completed`
- `run.failed`
- `run.cancelled`

终态规则：

- 一个 Run 只有一条终态；
- 取消经过 `cancelling`；
- 心跳不占用 `seq`；
- 客户端按 `seq` 去重。
